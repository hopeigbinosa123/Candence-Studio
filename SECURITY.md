# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Cadence Studio team takes security seriously. If you discover a security vulnerability in Cadence Studio:

1. **Do not create a public GitHub issue.**
2. Send a detailed description of the vulnerability, reproduction steps, and potential impact to security@cadence-studio.org.
3. The maintainers will acknowledge receipt within 48 hours and work with you to test and release a security patch.
